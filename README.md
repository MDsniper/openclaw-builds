# openclaw-builds

A collection of templates, tools, and setups for [OpenClaw](https://openclaw.ai) users.

Each folder is self-contained. Find the one you want, give your agent the link to its `DEPLOY.md`, and it will handle the rest.

---

## Contents

| Folder | What it is | Latest |
|--------|-----------|--------|
| [mission-control](./mission-control/) | Personal agent team dashboard (Next.js + SQLite) | [v1](./mission-control/v1/DEPLOY.md) |
| [skills](./skills/) | Reusable OpenClaw skills | — |
| [setups](./setups/) | Full environment setup guides | — |

---

## How to use

1. Find what you want in the table above
2. Copy the link to its `DEPLOY.md`
3. Tell your OpenClaw agent: *"Read this and deploy it: [URL]"*
4. Agent handles the rest
